# Contributing Guide

Thank you for your interest in contributing to Open Design Resource Kit.

## How to contribute

You can contribute by:

- Improving documentation
- Adding design templates
- Suggesting better checklist items
- Fixing unclear wording
- Translating resources between Korean and English

## Contribution process

1. Open an issue to suggest an idea.
2. Create or edit a Markdown file.
3. Submit a pull request.
4. The maintainer will review the contribution before merging.

## Style guide

- Keep language clear and practical.
- Use simple Markdown formatting.
- Focus on reusable design documentation.
- Avoid adding copyrighted design assets without permission.
