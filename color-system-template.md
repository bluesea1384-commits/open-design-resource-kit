# Color System Template

This template helps organize brand colors clearly and consistently.

## Primary colors

| Name | HEX | RGB | CMYK | Usage |
|---|---|---|---|---|
| Primary | #000000 | 0, 0, 0 | 0, 0, 0, 100 | Main brand color |

## Secondary colors

| Name | HEX | RGB | CMYK | Usage |
|---|---|---|---|---|
| Secondary | #FFFFFF | 255, 255, 255 | 0, 0, 0, 0 | Background color |

## Color usage rules

- Use primary colors for main brand recognition.
- Use secondary colors to support hierarchy.
- Maintain enough contrast between text and background.
- Avoid using too many colors in one layout.

## Accessibility notes

Check contrast when using color combinations for text, buttons, and interface elements.
