# Logo Guideline Template

This template helps document how a logo should be used across different media.

## Logo versions

- Primary logo
- Secondary logo
- Symbol only
- Wordmark only
- Black and white version

## Clear space

Define the minimum clear space around the logo to keep it visually recognizable.

## Minimum size

Define the minimum size for print and digital usage.

## Incorrect usage

Do not:

- Stretch or distort the logo
- Change the logo colors without permission
- Add shadows or effects
- Place the logo on low-contrast backgrounds
- Rotate or modify the logo shape

## File formats

Recommended formats:

- SVG for digital use
- PNG for general screen use
- PDF for print use
- AI or EPS for editable vector files
